# Netflix Movies and TV Shows – Exploratory Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on Netflix Movies and TV Shows data using Python. The objective is to explore Netflix's content library, identify patterns and trends, and gain insights into its content distribution.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## 📂 Dataset

The dataset contains information about Netflix titles, including:
- Title and content type
- Director and cast
- Country
- Date added to Netflix
- Release year
- Content rating
- Duration
- Genre and description

## 🔍 Analysis Performed

- Movies vs TV Shows distribution
- Content ratings analysis
- Netflix content additions over time
- Country-wise content distribution
- Genre analysis
- Movie duration and TV Show seasons
- Release year trends
- Content addition patterns by type and country
- Time gap between release year and Netflix addition

## 📊 Key Insights

- Movies account for approximately **69.6%** of the Netflix catalog, while TV Shows account for **30.4%**.
- **TV-MA** is the most common content rating.
- The United States contributes the largest number of titles, followed by India.
- **International Movies, Dramas, and Comedies** are the most frequently listed genres.
- Netflix content additions reached their peak in **2019**, with 1,999 titles.
- The median movie duration is **98 minutes**, while the median TV Show length is **1 season**.

1. Clone or download this repository.

   ```bash
   pip install pandas matplotlib seaborn plotly jupyter
   ```
3. Keep the notebook and CSV dataset in the same folder.
4. Open the notebook using Jupyter Notebook.
5. Run all cells to reproduce the analysis.
